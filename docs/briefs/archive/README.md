# Archived briefs

Completed Builder briefs, one file per round:

```
<NNN>-<YYYY-MM-DD>-<slug>.md
```

Zero-padded sequence number first, then the date, then a short slug. The
number is the primary sort key — dates alone stop disambiguating once two
rounds land on the same day.

Archive the brief **as Builder actually received it**, not as it was later
wished to have been written. If Brain amended the brief mid-round, record the
amendment at the bottom of the archived file rather than editing the original
text; a brief that was silently improved after the fact is useless as evidence
about how the round really went.

Outcome — accepted, rejected, or corrected — belongs in
[`../agents/model-notes.md`](../agents/model-notes.md) alongside what was
observed about the model that ran it.

Empty so far: no Builder round has run under this framework yet.
