pre-3.0.0 lifecycle. Nothing else was ever meant to belong here; current

This file deliberately makes **no claim about what this directory contains**.

had been filed here. Anything derivable from `ls` should be derived from `ls`
— a rehydration doc that asserts a fact a command can answer is a fact that
will eventually be wrong, and this directory's whole purpose is to be read
cold by someone who cannot tell.
