# Briefs (closed history)

This directory is the record of every round run before this project adopted
agentic-framework 3.0.0 in round 018-framework-3-0-0. It is frozen: no new
brief is written here, and `active.md` (the queued/active slot of the old
lifecycle) no longer exists. Current and future rounds live in
[`../rounds/`](../rounds/), one folder per round, per
[`docs/agents/FRAMEWORK.md`](../agents/FRAMEWORK.md).

The old lifecycle, kept only so the history below reads correctly: a brief
was `queued` or `active` in `active.md`, moved to [`delivered/`](delivered/)
once a PR existed but before review, and to [`archive/`](archive/) as
`accepted` or `rejected` once Brain adjudicated it. `archive/` means
adjudicated; nothing was ever parked there unreviewed.

Brief numbering (`NNN-YYYY-MM-DD-slug.md`) is superseded by round ids
(`NNN-short-slug`) in `docs/rounds/`; the two number sequences are
independent historical artefacts, not one continuing series.
